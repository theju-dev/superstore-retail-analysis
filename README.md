# Superstore Sales and Profit Analysis

## Project Overview

This project analyzes the Sample Superstore retail dataset using Python, Pandas, and Matplotlib.

The objective is to understand overall business performance, identify profitable and loss-making categories, investigate discount-related profitability issues, analyze geographic performance, and study sales and profit trends over time.

## Technologies Used

- Python
- Pandas
- Matplotlib

## Analysis Performed

- Data inspection and quality checks
- Missing value and duplicate analysis
- Date conversion and feature engineering
- Overall sales and profit KPIs
- Category and sub-category analysis
- Discount and profitability analysis
- State-level analysis
- State and sub-category drill-down
- Product-level loss analysis
- Customer and segment analysis
- Monthly and yearly trend analysis
- Business KPI summary
- CSV report generation
- Data visualizations

## Dataset

The project uses the public Sample Superstore dataset.
